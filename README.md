## 🤖 Featured AI & Machine Learning Projects

### 🧠 [Neural Network Digit Classifier](https://github.com/fictormarcel2/neural-network-digit-classifier)
*Developed a complete feedforward neural network in Python without relying on high level ML frameworks to classify MNIST handwritten digits.*
* **Architecture:** Formulated a structural 784 x 200 x 10 perceptron topology representing grayscale pixel inputs and digit outputs.
* **Core Mechanics:** Implemented full forward propagation and backpropagation algorithms utilizing vectorized matrix operations with NumPy.
* **Mathematical Optimization:** Applied sigmoid normalization functions and calculated explicit gradient descents to dynamically update the internal weight matrices (W_ih and W_ho) based on calculated output errors (E_out = T - O) and learning rates.
